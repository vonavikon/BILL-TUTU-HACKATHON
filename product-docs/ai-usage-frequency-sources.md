# Частота использования ИИ в планировании путешествий: подборка источников (2025–2026)

Список источников по темам для проверки и уточнения цифр из [ai-usage-frequency.md](ai-usage-frequency.md). Показывает разброс оценок между исследованиями (22–67%): разница объясняется разными вопросами (использовали ли ИИ вообще или именно для бронирования) и разными рынками.

## Общая статистика использования ИИ в планировании путешествий

**Phocuswright — «The AI Surge: Travel's Fastest Behavioral Shift in a Decade» (март 2026)**
- 56% путешественников США использовали ИИ для планирования, бронирования или помощи в поездке за последние 12 месяцев.
- Рост: 33% (первое полугодие 2025), 43% (второе полугодие 2025), 56% (первое полугодие 2026).
- Каждое поколение показало двузначный рост использования ИИ.
- 94% пользователей ИИ использовали его именно для целей, связанных с путешествиями.
- [Официальный отчёт Phocuswright](https://www.phocuswright.com/Travel-Research/Consumer-Trends/The-AI-Surge-Travels-Fastest-Behavioral-Shift-in-a-Decade)

**Global Rescue — «Fall 2025 Traveler Safety and Sentiment Survey» (декабрь 2025)**
- Опрос более 1500 путешественников.
- 22% респондентов использовали ИИ для планирования поездок; 30% среди путешественников не из США.
- 73% использовали ИИ для планирования маршрутов, 67% — для общего исследования, 35% — для поиска авиабилетов.
- 93% планируют использовать ИИ для следующей поездки.
- [Пресс-релиз Global Rescue](https://www.globalrescue.com/common/pressrelease/?duration=2025-2025&prId=54306)

**Kaspersky — исследование об использовании ИИ в путешествиях (август 2025)**
- 28% путешественников используют ИИ для планирования поездок.
- 96% из них удовлетворены результатом, 84% планируют использовать ИИ в будущем.
- Среди пользователей ИИ в путешествиях: 70% искали мероприятия, 66% — жильё, 60% — рестораны, 58% — авиабилеты.
- 45% бронировали отели через ИИ, 43% — авиабилеты.
- [Пресс-релиз Kaspersky](https://mac.kaspersky.es/about/press-releases/is-ai-underrated-as-a-travel-agent-kaspersky-survey-shows-only-28-of-travelers-use-ai-to-plan-their-trips-but-more-than-90-were-happy-with-the-results)

**Holafly — «Global eSIM & Travel Report 2025–2026» (2026)**
- 38% путешественников использовали ИИ для планирования поездок; ещё 35% хотели бы попробовать.
- Источник: esim.holafly.com.

**ABTA — «Holiday Habits Report 2025–2026» (октябрь 2025)**
- Количество использующих ИИ для поиска идей для путешествий удвоилось: с 4% до 8%.
- Источник: globetrender.com.

## Поиск и бронирование авиабилетов через ИИ

**PROS — анализ реферального трафика для авиакомпаний (ноябрь 2025)**
- ChatGPT обеспечил 2,3% реферального трафика для сайтов авиакомпаний в сентябре 2025 года; рост с 1,8% в августе 2025.
- ChatGPT составляет 95% всего ИИ-трафика авиакомпаний.
- [Статья Travel Weekly](https://www.travelweekly.com/Travel-News/Travel-Technology/OTAs-have-edge-over-airlines-ChatGPT)

**Adobe — данные о трафике ИИ на туристические сайты (июль 2025)**
- 3500% годовой рост трафика на туристические сайты, направляемого ИИ.
- Источник: Adobe Analytics.

**Европейские данные (2026)**
- 43% испанцев используют ИИ для поиска дешёвых авиабилетов.
- 21% швейцарцев используют ИИ-инструменты для планирования поездок (среди младше 45 лет — 29%).

## Данные по поколениям и демографии

**Adyen — «2025 Hospitality and Travel Report» (август 2025)**
- Опрос 41 000 потребителей в 28 странах.
- В ОАЭ: 68% путешественников используют ИИ для бронирования (+57% за год).
- По поколениям в ОАЭ: Gen Z — 77%, Millennials — 74%, Gen X — 44%, Boomers — 18%.
- [Пресс-релиз Adyen](https://www.adyen.com/en_AE/press-and-media/adyen-index-2025-hospitality-launch)

**European Travel Commission — ежеквартальный отчёт (ноябрь 2025)**
- Использование ИИ для планирования путешествий почти удвоилось: с 10% (2024) до 18% (2025).
- Самый высокий уровень использования: Китай — 40%, США — 27%.
- [Статья Travel Weekly UK](https://travelweekly.co.uk/news/gen-z-and-millennials-spearhead-surge-in-ai-travel-planning)

**Talker Research / New York Post — опрос 2000 американцев (август 2025)**
- 29% миллениалов и 33% поколения Z никогда не использовали ИИ для планирования путешествий.
- Источник: NY Post.

**Phocuswright — данные по поколениям (2025)**
- Миллениалы лидируют по использованию генеративного ИИ для путешествий.
- Источник: phocuswright.com.
