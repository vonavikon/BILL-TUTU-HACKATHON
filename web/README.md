# tutu — выбор места в поезде (web-каркас)

Десктопный React-каркас трёх экранов продукта: главная с одним инпутом,
чат + чек-лист поездки, готовый план с схемой вагона. Данные — статические
моки (`src/mocks/`), без подключения к реальному MCP/LLM.

## Запуск

```bash
npm install
npm run dev
```

## Тесты

```bash
npm test
```

## Структура

- `src/pages/` — три экрана-роута: `Home`, `TripChecklist`, `TripPlan`
- `src/components/` — переиспользуемые UI-блоки (чат, чек-лист, карточки плана)
- `src/state/TripContext.tsx` — состояние чата и чек-листа, общее между экранами 2 и 3
- `src/mocks/` — моковые поезда, тариф, схема вагона, сценарий диалога
- `src/lib/checklist.ts` — чистая логика чек-листа (без React), покрыта тестами
